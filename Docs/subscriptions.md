## Добавление подписки

Нажмите **+** в правом верхнем углу экрана «Подписки».

| Поле | Описание | Обязательное |
|------|----------|:---:|
| **Название** | Произвольное имя подписки | да |
| **Сумма** | Стоимость одного платежа | да |
| **Валюта** | USD, EUR, RUB, BYN, GEL | да |
| **Цикл оплаты** | Как часто списывается платёж | да |
| **Дата начала** | Дата первого платежа (или покупки) | да |
| **Категория** | Произвольная метка (например, «Развлечения») | нет |
| **Иконка** | SF Symbol для визуального оформления | нет |

После сохранения подписка сразу появляется в списке.

## Циклы оплаты

| Цикл | Описание | Ежемесячная стоимость |
|------|----------|-----------------------|
| **Еженедельно** | Платёж раз в 7 дней | сумма × 52 ÷ 12 |
| **Ежемесячно** | Платёж раз в месяц | сумма |
| **Ежеквартально** | Платёж раз в 3 месяца | сумма ÷ 3 |
| **Ежегодно** | Платёж раз в год | сумма ÷ 12 |
| **Разово** | Единоразовая покупка | не учитывается в месячном итоге |

> Нормализованная ежемесячная стоимость показывается в строке подписки рядом с датой следующего платежа, если цикл отличается от ежемесячного.

## Валюты

Поддерживаемые валюты: **USD**, **EUR**, **RUB**, **BYN**, **GEL**.

Итоги (ежемесячный и годовой расходы) рассчитываются отдельно для каждой валюты — смешение не происходит.

## Экран списка

Переключение между режимами осуществляется сегментированным переключателем в левом верхнем углу:

- **Список** — управление подписками
- **Отчёт** — графики и аналитика

### Секция «Скоро оплата»

Показывается автоматически, если в течение ближайших **7 дней** предстоит платёж по одной или нескольким подпискам. Отображает название, сумму и дату платежа.

Для разовых покупок секция появляется, если дата покупки попадает в ближайшую неделю.

### Секция «Итого в месяц»

Показывает суммарный ежемесячный расход по **активным рекуррентным** подпискам отдельно для каждой валюты. Разовые покупки в итог не входят.

### Фильтры

Горизонтальная строка чипов над списком позволяет быстро переключать представление:

| Фильтр | Что показывает | Сортировка |
|--------|----------------|------------|
| **Все** | Все подписки независимо от статуса | По дате добавления (новые сверху) |
| **Активные** | Только активные подписки | По дате следующего платежа |
| **Отменённые** | Только отменённые подписки | По дате отмены (последние сверху) |
| **Оплаченные** | Разовые покупки с прошедшей датой | По дате покупки (последние сверху) |

При переключении фильтра список автоматически возвращается на первую страницу.

### Пагинация

Количество записей на странице выбирается в заголовке секции (меню рядом со счётчиком):

- **5** — по 5 записей
- **10** — по 10 записей (по умолчанию)
- **Все** — без ограничений

При наличии нескольких страниц в нижней части секции отображается навигационная строка «Стр. X из Y» с кнопками «<» и «>».

## Редактирование подписки

Нажмите на любую строку списка — откроется форма редактирования с теми же полями, что и при добавлении.

Дополнительно доступен переключатель **Активна**. При отключении появляется поле **Дата окончания** — дата, когда подписка была отменена.

---

## Отмена подписки

Отмена — это мягкое деактивирование подписки с сохранением истории платежей.

1. Откройте форму редактирования (нажмите на строку).
2. Отключите переключатель **Активна**.
3. Укажите **Дату окончания** (по умолчанию — сегодня).
4. Сохраните.

После отмены:
- Подписка отображается в фильтре **Отменённые** с пометкой даты отмены.
- В отчёте платежи учитываются только до даты отмены.
- Плановые уведомления снимаются.

Для реактивации снова включите переключатель **Активна** в форме редактирования.

---

## Удаление подписки

Проведите по строке влево и нажмите **Удалить** (или используйте кнопку удаления в подтверждающем диалоге).

> **Внимание:** удаление необратимо. Вся история и данные подписки будут удалены. Если вы хотите сохранить историю — используйте [отмену](#отмена-подписки).

## Экран отчёта

Переключитесь на вкладку с иконкой графика в левом верхнем углу.

### Карточки итогов

Прокручиваемая горизонтальная панель карточек. Для каждой валюты показывает:

- Количество активных подписок
- Ежемесячные расходы (рекуррентные)
- Годовые расходы (рекуррентные)

### График платежей по месяцам

Столбчатый график реальных платежей за выбранный год. Каждый столбец — месяц, каждый цвет — валюта. Над столбцами отображается итоговая сумма за месяц.

- Переключение года — стрелками «<» и «>» справа от заголовка.
- Текущий месяц выделяется подсветкой фона.
- Отменённые подписки включаются в график вплоть до даты отмены.
- Разовые покупки появляются в месяце их даты.

### Предстоящие платежи (30 дней)

Список активных подписок, у которых дата следующего платежа — в ближайшие 30 дней. Показывается только при наличии таких подписок.

### Годовая разбивка

Таблица активных рекуррентных подписок с годовой стоимостью каждой и итогом по валюте.

## Уведомления

Приложение отправляет push-уведомление **за 1 день до** очередной даты платежа по каждой активной рекуррентной подписке.

- Уведомления планируются автоматически при добавлении или обновлении подписки.
- При отмене или удалении подписки запланированное уведомление снимается.
- Требуется разрешение на отправку уведомлений (запрашивается при добавлении первой подписки).

## Экспорт в CSV

В разделе **Настройки → Экспорт данных** нажмите **Экспорт подписок**.

Файл `subscriptions.csv` содержит следующие поля:

| Поле | Описание |
|------|----------|
| `ID` | Уникальный идентификатор |
| `Title` | Название |
| `Category` | Категория |
| `Amount` | Сумма платежа |
| `Currency` | Валюта |
| `BillingCycle` | Цикл оплаты |
| `StartDate` | Дата первого платежа (ISO 8601) |
| `EndDate` | Дата отмены (ISO 8601, пусто для активных) |
| `IsActive` | `true` / `false` |
| `CreatedAt` | Дата добавления (ISO 8601) |

После генерации файла открывается стандартный системный диалог — можно сохранить в «Файлы», отправить по почте или поделиться любым другим способом.

## Статусы подписок

| Статус | Цвет | Условие |
|--------|------|---------|
| **Активна** | Зелёный | `isActive = true`, рекуррентная или разовая с будущей датой |
| **Оплачено** | Синий | `isActive = true`, разовая, дата покупки уже прошла |
| **Отменена** | Серый | `isActive = false` |

Отменённые подписки отображаются с прозрачностью 60%, чтобы визуально отделить их от активных.
